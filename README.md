# PXG Hunt Journal — Windows releases

Private local hunt journals for PokeXGames. Download the latest Windows installer from [Releases](https://github.com/Jessewhalen1992/pxg-hunt-journal-releases/releases/latest).

This repository contains distribution files and update metadata. Personal journals and exports stay on each user's computer. No Git installation, GitHub account or app account is required.

Download the ZIP bundle for the installer, bilingual changelog, setup/upgrade instructions and image credits. Install using the same Windows account as before to keep the journal. From version 1.1.34, use **Import & backup → App updates** for future updates. The app saves and backs up the current journal locally before an update and waits for you to choose **Restart and install**.

## Português

Baixe o instalador mais recente para Windows em [Releases](https://github.com/Jessewhalen1992/pxg-hunt-journal-releases/releases/latest). O ZIP inclui o instalador, o histórico de alterações bilíngue, as instruções de instalação/atualização e os créditos das imagens.

Instale com a mesma conta do Windows para preservar o diário. A partir da versão 1.1.34, use **Importação e backup → Atualizações do aplicativo** nas próximas atualizações. O aplicativo salva o diário e cria um backup local antes de atualizar, aguardando você escolher **Reiniciar e instalar**.
